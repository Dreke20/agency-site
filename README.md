# Dirty South Marketing Agency

Public site for [dirtysouthagency.com](https://dirtysouthagency.com/).

This is a plain static site (HTML, CSS, and images) served with GitHub Pages. The custom domain is set in `CNAME`.

The site also has short service pages (`/google-business-profile/`, `/marketing/`, `/websites/`, `/seo/`, `/apps/`), plus `robots.txt`, `sitemap.xml`, and `llms.txt` for search and AI crawlers.
